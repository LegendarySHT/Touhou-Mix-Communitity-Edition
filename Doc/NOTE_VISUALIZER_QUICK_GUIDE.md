# 音符可视化快速使用指南

## 🎵 功能说明

TrackView 中集成的音符可视化用于 MIDI 预览时的实时音符显示。

## 🚀 使用步骤

### 1. 进入 TrackView

1. 在 MidiView（MIDI 详情页）中选择一个谱面
2. 点击 **"进入轨道视图"** 按钮
3. 自动进入 TrackView

### 2. 查看音符

#### 总览显示区（顶部）
- 显示所有轨道的音符
- 多车道显示，每个轨道对应一个车道
- 显示 "已通过音符数 / 总音符数"

#### 各轨道显示区（下方列表）
- 每个轨道独立显示自己的音符
- 可通过"启用/禁用"按钮控制该轨道音符的显示

### 3. 播放预览

1. 点击 **"播放预览"** 按钮
2. 音符开始从右向左滚动
3. 播放位置实时更新

### 4. 控制播放

- **拖动进度条**: 跳转到指定位置，音符自动更新
- **再次点击**: 停止预览

## 🎨 视觉说明

### 音符颜色
- 根据音高（pitch）自动着色
- 同一音高（不同八度）显示相同颜色
- 使用 HSV 色轮分配颜色

### 音符大小
- **宽度**: 表示持续时间（duration）
- **高度**: 固定高度，占车道高度的 80%

### 位置计算
- **横向**: 从右向左移动，到达左侧边缘表示播放完成
- **纵向**: 按轨道号分配车道

## ⚙️ 技术参数

| 参数 | 说明 |
|------|------|
| 车道数 | 小窗口: 12，大窗口: 24 |
| 缩放因子 | 0.5 (tick → 像素) |
| 更新频率 | 每帧（60 FPS） |

## 💡 提示

- **窗口大小**: 放大窗口可显示更多车道（12→24）
- **轨道过滤**: 禁用某些轨道可减少显示的音符
- **性能**: 大型 MIDI 文件（>10000 音符）可能有轻微卡顿

## 🐛 已知问题

- 极短的音符（duration < 10 tick）可能显示为细线
- 轨道数超过车道数时会循环分配，可能导致重叠
